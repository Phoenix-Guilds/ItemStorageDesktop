# История изменений

## [0.1.12] - 2026-10-30

### Добавлено
- Автозапуск программы вместе с Windows. Его можно отключить в настройках.
- Временные метки с точностью до секунды для сообщений в журнале.

### Улучшено
- Настройки открываются в отдельном модальном окне с ранее сохраненными значениями; окно можно закрыть без сохранения.
- Обновлена верхняя часть окна: название программы и кнопка настроек расположены в одной строке, журнал получил понятный подзаголовок.
- В заголовке окна отображается текущая версия программы.
